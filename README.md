# Dashboard with Agent Integration

A comprehensive Streamlit dashboard with leaderboards, graphs, timelines, and detail cards for users and groups. The application is connected to a PostgreSQL database and features enhanced agent capabilities to process various data inputs through an interactive chat interface.

## Features

- **Interactive Dashboard**
  - Leaderboards for tracking performance
  - Visualizations for user and group analytics
  - Timeline views of activities
  - Detailed user and group profile cards

- **Enhanced Agent Interface**
  - Interactive chat UI with improved message handling and visual styling
  - Process Excel files and extract structured data
  - Extract data from documents with intelligent parsing
  - Natural language interactions via the chat interface
  - Update the database through various agent tools

## Setup

1. Install dependencies:
```
pip install -r requirements.txt
```

2. Run the Streamlit dashboard:
```
streamlit run app/dashboard.py
```

## Docker Deployment

### Quick Start

To run the application using Docker:

```bash
# Build and start containers
docker-compose up -d

# View logs
docker-compose logs -f

# Stop containers
docker-compose down
```

The Streamlit dashboard will be available at http://localhost:8501

### Container Architecture

The Docker Compose setup includes:

1. **Streamlit Dashboard Container**
   - Built from the project's Dockerfile
   - Automatically waits for PostgreSQL to be ready before starting
   - Includes healthchecks to ensure the application is running properly
   - Exposes port 8501 for the web interface

2. **PostgreSQL Database Container**
   - Uses the official PostgreSQL 14 image
   - Persistent data stored in a Docker volume
   - Exposes port 5432 for database connections
   - Includes healthcheck to verify database availability

### Environment Variables

The following environment variables can be configured:

#### Database Configuration
```
DB_TYPE=postgres          # Database type (postgres or sqlite)
POSTGRES_HOST=db          # PostgreSQL host
POSTGRES_PORT=5432        # PostgreSQL port
POSTGRES_USER=dashboard_user      # PostgreSQL username
POSTGRES_PASSWORD=dashboard_password  # PostgreSQL password
POSTGRES_DB=dashboard     # PostgreSQL database name
DB_PATH=/data/dashboard.db    # SQLite database path (backup option)
```

### Data Persistence

The application data is persisted in two ways:

1. PostgreSQL data is stored in a Docker volume named `postgres_data`
2. Any files generated by the application are stored in the `./data` directory

### Custom Configuration

To customize the deployment, edit the following files:

- `docker-compose.yml` - To modify container settings, ports, and volumes
- `Dockerfile` - To change the base image, add dependencies, or modify the build process
- Environment variables in `docker-compose.yml` - To configure database connection parameters
